# Ambient Source Family

**Role:** Source/style family, not always a user-facing mode

## Direction

Ambient is the source library that feeds Relax, Meditate, and possibly Sleep. It's not always a final destination — it's the raw materials: nature recordings, generated drones, texture layers.

## Source Categories

- **Nature:** rain, stream, wind, ocean, birds, fire, cave
- **Drone:** generated pads, sub bass, sustained tones
- **Texture:** gongs, bowls, bells, chimes
- **Noise:** brown, pink, white (for Sleep)

## How It Feeds Other Categories

| Category | Ambient Sources Used |
|----------|---------------------|
| Relax | Nature (rain, stream, wind, ocean) + subdued drone |
| Meditate | Texture (gongs, bowls) + minimal drone |
| Sleep | Noise (brown/pink) + barely audible drone |
| Focus | Not nature-first — uses generated music |
| Deep Work | Some drone sources possible |
